# hackthon.

AI-powered Doubt Solver — a tool for subject-wise Q&A, previous paper analysis, and PDF-based question answering using Retrieval-Augmented Generation (RAG).

Features
- Subject-wise chat interface
- PDF ingestion and QA
- Previous paper analysis and insights
- Retrieval-Augmented Generation for accurate answers

Quick start
1. Clone the repo:

	git clone https://github.com/yashsghodke-svg/hackthon..git

2. Backend: open `BackEnd/` and follow its README to install dependencies and run the server.

3. Frontend: open `FrontEnd/` and follow its README to install dependencies and run the client.
