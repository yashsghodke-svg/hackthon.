# Contributing

Thanks for your interest in contributing! A few guidelines to help us review and accept your contribution:

- Search existing issues before opening a new one.
- For bug fixes, include a minimal reproduction and tests if applicable.
- For new features, open an issue first to discuss design.
- Keep PRs focused and small; one logical change per PR.

Workflow
1. Fork the repository and create a branch: `feature/your-feature` or `fix/issue-number`.
2. Run linters and tests locally before opening a PR.
3. Open a pull request against `main` with a clear title and description.

Review
- PRs are reviewed by maintainers; address review comments promptly.
- Squash or rebase as requested.

See also: [CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md) and [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md).
